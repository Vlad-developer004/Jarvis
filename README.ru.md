# JARVIS — офлайн голосовой ассистент для Windows

*[English version](README.md)*

Это офлайн голосовой ассистент для Windows: вы говорите — он действует. Документ ниже — вступление и справочник: что это, в чём реально сильные стороны, как поставить и запустить, и где ещё есть шероховатости.

---

## Что это

Фоновая программа для Windows, которая слушает wake word («Джарвис»), превращает речь в одну из ~280 базовых распознаваемых команд и выполняет её — открывает приложения, управляет окнами/файлами/буфером обмена, следит за игрой, озвучивает состояние системы и многое другое. Поверх этой базы игровые профили и расширения добавляют свои собственные наборы голосовых макросов, когда актуально (Euro Truck Simulator 2, Farming Simulator 22, Hogwarts Legacy, Planetbase, Photoshop, Figma — у каждого ещё по несколько десятков своих команд), так что реальное число в активной сессии заметно выше. Распознавание речи, понимание команд и синтез голоса работают полностью на устройстве — ничего из сказанного не уходит наружу, если только конкретная фича сама не требует сети (погода, YouTube, картинка дня NASA, опциональные облачные ответы ИИ).

## Сильные стороны — что здесь реально сделано хорошо

- **Полностью локально по умолчанию.** ASR (Vosk/sherpa-onnx), классификация намерений и TTS (Silero) не требуют интернета и никуда ничего не отправляют. Сетевые запросы происходят только там, где это фиче реально нужно, и каждая — опционально.
- **Слоёное распознавание намерений, а не один хрупкий матчер.** Фраза проходит через таблицу точных ключевых слов, затем семантический классификатор (эмбеддинги предложений + сходство с центроидами с явным гейтом «margin of confidence», который отвергает неоднозначный ввод вместо угадывания), затем нечёткий rule-based матчер — и только потом, если ничего не сработало, попадает в локальную LLM. Каждый слой дешёвый, и более дорогие уровни оплачивает только то, что не распозналось раньше.
- **Автотесты.** 2000+ тестов (юнит, интеграционные — на реальной GGUF-модели, и покрытие интерактивных состояний), часть из которых написана специально для отлова реальных багов распознавания команд.
- **Осторожность с необратимыми действиями заложена намеренно.** Выключение, перезагрузка, удаление, очистка и всё, что сложно отменить, всегда спрашивают голосовое подтверждение да/нет перед выполнением — в том числе когда запрос пришёл из более нечёткого локального LLM-фолбека, а не из точного матчера.
- **Сделано под реальную многозадачность**, в частности под игры: полноценная интеграция с Euro Truck Simulator 2, которая сама предупреждает о топливе, усталости, штрафах и износе техники во время игры, без запроса.
- **Расширяется без правок ядра**: новые голосовые макросы, игровые профили и интеграции с приложениями регистрируются через Менеджер расширений, а не через хардкод в коде.

## Известные шероховатости (стоит прочитать перед тем, как полагаться на это)

- **Локальный LLM-фолбек** (см. ниже) — маленькая модель на 1B параметров, работающая только на CPU. Это последний слой для фраз, которые не распознал никто другой, и он будет иногда ошибаться или отвечать коряво — это ожидаемо для такого размера модели, а не баг, о котором нужно сообщать. Воспринимайте это как рабочую инфраструктуру с моделью, которую можно улучшить позже, а не как законченную фичу.
- Часть edge-кейсов в распознавании команд всё ещё находится и чинится по мере реального использования. Если фраза распозналась неверно — сообщайте, это полезно: несколько реальных багов уже найдены и исправлены именно так, и закреплены регресс-тестами.
- **Распознавание лица в режиме охраны** — это лёгкий DNN-детектор плюс простой классификатор, а не серьёзная биометрия: при плохом освещении или необычном ракурсе возможны ложные срабатывания или пропуски. Воспринимайте как полезное уведомление в Telegram, а не как защищённую систему безопасности.

## Быстрый старт

```bash
git clone <URL этого репозитория>
cd Jarvis
pip install -r requirements.txt
cp .env.example .env   # опционально: для Telegram-бота, ответов ИИ, почты — без этого Джарвис тоже нормально работает
python main.py
```

При самом первом запуске откроется окно-приветствие: там можно выбрать, как к вам обращаться, и сразу увидеть карточки с ключевыми возможностями. Дальше просто скажите **«Джарвис»**.

### Уровни зависимостей

`requirements.txt` тянет только базовый набор (`requirements-base.txt`) — этого достаточно для голосового управления, диктовки, таймеров, файлов и системных команд. Часть фич требует дополнительных пакетов и без них просто тихо отключается, не ломая остальное:

| Файл | Что даёт |
|---|---|
| `requirements-base.txt` | ASR/TTS (Vosk, sherpa-onnx, Silero), семантический NLU, локальный ИИ-фолбек (llama-cpp-python), базовые системные команды |
| `requirements-vision-game.txt` | OpenCV — превью видео NASA «картинки дня», охрана по камере |
| `requirements-web-qa.txt` | `yt-dlp` — поиск/скачивание YouTube, ответы ИИ (Groq/OpenAI/Gemini) |
| `requirements-system-optional.txt` | Управление Wi-Fi через WinRT API |
| `requirements-full.txt` | Всё вместе |
| `requirements-dev.txt` | + `pytest`, `pyflakes` для разработки |

Ставьте `requirements-full.txt`, если хотите сразу все возможности без сюрпризов.

## Как общаться с Джарвисом (Wake Word)

По умолчанию Джарвис «спит» и не реагирует на разговоры вокруг — так и должно быть, это не подслушивание. Чтобы он услышал, скажите **«Джарвис»**.

После этого он остаётся активным некоторое время (по умолчанию 30 секунд, **настраивается ползунком** в Настройки → Голос) и не требует повторять имя перед каждой командой. В тех же настройках можно выбрать:

- **Один ответ на имя** — «Да, сэр» только при пробуждении, дальше тихо продлевает окно активности без спама.
- **Всегда отвечать на имя** — подтверждает каждый раз, когда слышит своё имя.

Если фраза не распозналась — Джарвис теперь **скажет об этом вслух** («не расслышал, повторите») вместо того, чтобы промолчать, так что вы всегда понимаете, услышал он вас или нет.

## База команд — если забыли, что можно сказать

Команд очень много, и запоминать их не нужно. В любой момент скажите:

> «покажи все команды» / «база команд»

— и откроется окно со **всеми** голосовыми командами по категориям, с несколькими вариантами формулировки на каждую (например, для паузы подойдёт и «пауза», и «стоп», и «останови»). То же окно доступно по кнопке ◈ в интерфейсе.

## Что умеет Джарвис

**Уборка и система**
- «Джарвис, приберись» — очистка временных файлов, кэшей браузеров, корзины, освобождение памяти.
- «Выключи компьютер через час», «выключи блютуз», «включи вайфай».

**Интернет и медиа**
- «Открой ютуб», «найди в интернете рецепт пиццы».
- «Включи песню X» — если YouTube выдал несколько похожих видео (клип/live/кавер), Джарвис покажет карточки с превью и предложит выбрать кликом или голосом («второе»).
- «Покажи картинку дня от наса» — астрономическое фото или видео дня NASA с описанием, прямо в окне ассистента, без браузера.

**Игры (Euro Truck Simulator 2 и другие)**
- «Статус грузовика», «круиз-контроль на 90», «прибавь ретардер».
- Джарвис сам предупредит о топливе, усталости водителя, штрафах, износе техники, сцепке/расцепке прицепа — без запроса, во время игры.
- ИИ озвучивает брифинг перед рейсом и итоги после сдачи груза (нужен ключ Groq/OpenAI/Gemini).

**Режим охраны (оповещение о постороннем через веб-камеру)**
- «Включи режим охраны» — пока вас нет, веб-камера периодически проверяет наличие лица; первый снимок «запоминается» как владелец.
- Если обнаружено лицо, не совпадающее с владельцем, Джарвис сохраняет снимок и, если настроен Telegram-бот (см. ниже), сразу присылает фото с тревогой.
- Нужен `requirements-vision-game.txt` (OpenCV), при первом использовании скачивается небольшая модель распознавания лиц.

**Удалённое управление через собственного Telegram-бота**
- После настройки `TELEGRAM_BOT_TOKEN`/`TELEGRAM_CHAT_ID` (см. `.env.example`) Джарвис слушает чат вашего бота и прогоняет любое текстовое сообщение через тот же самый матчер команд, что и голос — то есть можно управлять голосовыми командами удалённо, просто написав боту.
- Тот же токен/chat ID используется и для фотооповещений режима охраны выше.
- **Настройка**: напишите [@BotFather](https://t.me/BotFather) в Telegram, `/newbot`, получите токен — затем напишите что-нибудь своему новому боту и узнайте свой chat ID (например, через `https://api.telegram.org/bot<ТОКЕН>/getUpdates`). Впишите оба значения в `.env` как `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Пока эти переменные не заданы — обе фичи полностью отключены, без ошибок, и никто посторонний не может увидеть или использовать вашего бота.

**Помощник и заметки**
- «Напомни выключить духовку через 20 минут».
- «Режим диктовки» — печатает голосом в любое текстовое поле со знаками препинания.
- Голосовые напоминания о событиях календаря (читает ваш `.ics`), голосовые оповещения о низком заряде батареи, быстрые ссылки на созвоны («присоединиться к митингу» открывает сохранённую ссылку Zoom/Meet/Teams).

**Локальный ИИ-фолбек (офлайн, инфраструктура готова, качество модели пока ограничено)**
- Если фраза не совпала ни с одной известной командой, вместо тишины Джарвис отдаёт её маленькой локальной LLM (LoRA-дообученная Vikhr-Llama-3.2-1B, GGUF, только CPU — без облака и оплаты API) через `core/speech/llm_chat.py`.
- Модель либо резолвит запрос в реальное действие (function-calling по списку интентов, через уже существующие семантические эмбеддинги — не по жёстко зашитому списку) и выполняет его через обычный dispatch-пайплайн, либо отвечает в стиле персоны Джарвиса, озвучивая ответ по мере генерации, предложение за предложением. Также помнит короткий контекст диалога, так что быстрые уточнения работают.
- Необратимые/разрушительные действия (выключение, перезагрузка, удаление, очистка и т.д.) всегда спрашивают голосовое подтверждение да/нет перед выполнением — нечёткое распознавание LLM никогда не выключит компьютер само по себе.
- Тумблер: Настройки → Модули → «Локальный ИИ (фолбек)»; таймаут удержания в памяти настраивается в Настройки → Голос.
- **Без завышенных ожиданий**: это 1B-модель, работающая только на CPU как *фолбек* позади точного матчера, семантического классификатора и нечёткого rule-based матчера — она видит только те фразы, которые не распознал никто из них. Она будет иногда ошибаться или отвечать коряво, она не заменяет основные пути распознавания, и объективно не стоит ждать от неё надёжности облачной модели. Что реально прочно сделано — это *инфраструктура* вокруг: function-calling с grammar-ограничением, отбор кандидатов через retrieval, контекст диалога, потоковое озвучивание, подтверждение деструктивных действий — всё это остаётся рабочим и улучшаемым независимо от того, какая модель стоит за ней. Подмена на более крупный/качественный файнтюн в будущем не требует правок кода.

**Прочее**
- Голосовые макросы для приложений (Photoshop, Figma и другие через Менеджер расширений).
- Мониторинг ресурсов ПК, управление окнами, буфером обмена, почтой.

## Где искать настройки

Кнопка с шестерёнкой ⚙️ в интерфейсе, либо голосом: «открой настройки».

- **Вкладка «Голос»** — чувствительность микрофона, усиление, режим wake word и таймер «засыпания», калибровка одной кнопкой, таймаут удержания локального ИИ в памяти.
- **Вкладка «Интерфейс»** — темы, прозрачность, масштаб.
- **Менеджер расширений** — игровые профили и доп. навыки, устанавливаются по необходимости.
- **Вкладка «Модули»** — тумблеры отдельных фич, включая локальный ИИ-фолбек выше.

## Сборка в готовый `.exe`

Всё собирается через PyInstaller по спеке `jarvis.spec`, обёрнутой в `build.bat`.

```bash
pip install -r requirements-full.txt   # чтобы в сборку попали все опциональные фичи
pip install pyinstaller
build.bat
```

Скрипт сам:
1. Прогоняет PyInstaller по `jarvis.spec` (это может занять несколько минут — Silero TTS тянет PyTorch).
2. Копирует `assets/`, `audio/`, `models/`, `config_pack/` рядом с `Jarvis.exe`.
3. Копирует статичные данные (игровые профили, каталог расширений, ONNX-модель семантического NLU, кэш эмбеддингов) в `dist\Jarvis\data\` — но **не** ваши личные `jarvis_settings.json`, `.env`/`secrets.env` и логи, чтобы случайно не утекли API-ключи или история.

Результат — папка `dist\Jarvis\` с `Jarvis.exe` и всем необходимым рядом; переносится на другой ПК как есть (Windows 10/11 x64).

Если нужен инсталлятор (а не просто папка) — используйте `build_installer.bat` (собирает через `jarvis_installer.iss`, Inno Setup).

**Что НЕ копируется намеренно** (и это правильно): личные настройки, история команд, сохранённые API-ключи, отладочные логи — при первом запуске на новой машине они создадутся заново.

## Зачем это нужно

1. **Многозадачность** — не отвлекаясь на поиск нужной папки или настройки, особенно за рулём в игре.
2. **Скорость** — команды вроде очистки памяти или проверки погоды выполняются голосом за секунду.
3. **Приватность** — распознавание речи и логика команд работают локально; в интернет уходят только явно сетевые запросы (погода, YouTube, NASA, ИИ), и только если вы ими пользуетесь.

Если что-то работает не так — откройте Настройки → Голос → «ТЕСТ И КАЛИБРОВКА», это чинит 90% проблем с распознаванием.
