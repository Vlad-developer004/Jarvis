2. ЧТО ДЕЛАЕТ ПРОГРАММА (ОЗНАКОМЬТЕСЬ ПЕРЕД УСТАНОВКОЙ)

Программа — голосовой ассистент, который в процессе работы:
  - слушает микрофон постоянно, распознавая речь офлайн (без отправки
    аудио в интернет для базовых голосовых команд);
  - управляет системными функциями Windows по голосовой команде:
    громкость, яркость, Wi-Fi/Bluetooth, блокировка/разблокировка
    клавиатуры, перезагрузка и выключение компьютера, работа с файлами
    и папками (включая создание и удаление);
  - эмулирует нажатия клавиш и движения мыши (в том числе для игровых
    профилей и функции «нажми и говори», использующей низкоуровневый
    системный хук клавиатуры Windows — некоторые антивирусы могут
    ошибочно пометить это поведение как подозрительное);
  - может по вашему явному включению отправлять текстовые запросы
    внешнему облачному ИИ-сервису (например, Groq) для функции чата —
    это происходит только при наличии настроенного ключа API и только
    для тех запросов, для которых вы явно вызвали эту функцию;
  - по вашему явному включению («режим охраны») использует веб-камеру
    для обнаружения лица, сохраняет локальные снимки владельца и
    постороннего и, при настроенном Telegram-боте, отправляет фото
    постороннего в ваш Telegram;
  - по вашему явному включению (настройка собственного Telegram-бота)
    принимает текстовые сообщения из вашего Telegram-чата и выполняет
    их как голосовые команды — включая системные действия, перечисленные
    выше (удаление файлов, выключение компьютера и т.д.);
  - самостоятельно проверяет наличие обновлений и может перезаписывать
    собственные файлы в папке установки.

Устанавливая и используя Программу, вы подтверждаете, что понимаете
перечисленный выше функционал и принимаете связанные с ним риски.

3. ДАННЫЕ

Программа хранит настройки и учётные данные локально на вашем компьютере
(в папке %APPDATA%\Jarvis). Разработчик не собирает и не передаёт себе
никакие данные пользователя.
