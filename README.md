# 🎙️ JARVIS — офлайн голосовой ассистент для Windows

Добро пожаловать в мир JARVIS — вашего личного голосового ассистента! Это руководство поможет разобраться, **что это такое, как его запустить, как им пользоваться и как собрать готовый `.exe`.**

---

## 🧐 Что такое JARVIS?

JARVIS — программа для Windows, с которой можно **разговаривать**. В отличие от Алисы или Siri, JARVIS работает **полностью локально**: распознавание речи, понимание команд и синтез голоса не требуют интернета и никуда ничего не отправляют. Интернет нужен только для опциональных вещей — погоды, курса валют, картинки дня NASA, поиска на YouTube и ответа ИИ (если вы сами подключили ключ).

---

## 🚀 Быстрый старт

```bash
git clone <URL этого репозитория>
cd Jarvis
pip install -r requirements.txt
python main.py
```

При самом первом запуске откроется окно-приветствие: там можно выбрать, как к вам обращаться, и сразу увидеть карточки с ключевыми возможностями. Дальше просто скажите **«Джарвис»**.

### Уровни зависимостей

`requirements.txt` тянет только базовый набор (`requirements-base.txt`) — этого достаточно для голосового управления, диктовки, таймеров, файлов и системных команд. Часть фич требует дополнительных пакетов и без них просто тихо отключается, не ломая остальное:

| Файл | Что даёт |
|---|---|
| `requirements-base.txt` | ASR/TTS (Vosk, sherpa-onnx, Silero), семантический NLU, базовые системные команды |
| `requirements-vision-game.txt` | OpenCV — превью видео NASA «картинки дня», охрана по камере |
| `requirements-web-qa.txt` | `yt-dlp` — поиск/скачивание YouTube, ответы ИИ (Groq/OpenAI/Gemini) |
| `requirements-system-optional.txt` | Управление Wi-Fi через WinRT API |
| `requirements-full.txt` | Всё вместе |
| `requirements-dev.txt` | + `pytest`, `pyflakes` для разработки |

Ставьте `requirements-full.txt`, если хотите сразу все возможности без сюрпризов.

## 🗣️ Как общаться с Джарвисом (Wake Word)

По умолчанию Джарвис «спит» и не реагирует на разговоры вокруг — так и должно быть, это не подслушивание. Чтобы он услышал, скажите **«Джарвис»**.

После этого он остаётся активным некоторое время (по умолчанию 30 секунд, **настраивается ползунком** в Настройки → Голос) и не требует повторять имя перед каждой командой. В тех же настройках можно выбрать:

- **Один ответ на имя** — «Да, сэр» только при пробуждении, дальше тихо продлевает окно активности без спама.
- **Всегда отвечать на имя** — подтверждает каждый раз, когда слышит своё имя.

Если фраза не распозналась — Джарвис теперь **скажет об этом вслух** («не расслышал, повторите») вместо того, чтобы промолчать, так что вы всегда понимаете, услышал он вас или нет.

## ◈ База команд — если забыли, что можно сказать

Команд очень много, и запоминать их не нужно. В любой момент скажите:

> «покажи все команды» / «база команд»

— и откроется окно со **всеми** голосовыми командами по категориям, с несколькими вариантами формулировки на каждую (например, для паузы подойдёт и «пауза», и «стоп», и «останови»). То же окно доступно по кнопке ◈ в интерфейсе.

## 🛠️ Что умеет Джарвис

**🧹 Уборка и система**
- «Джарвис, приберись» — очистка временных файлов, кэшей браузеров, корзины, освобождение памяти.
- «Выключи компьютер через час», «выключи блютуз», «включи вайфай».

**🌐 Интернет и медиа**
- «Открой ютуб», «найди в интернете рецепт пиццы».
- «Включи песню X» — если YouTube выдал несколько похожих видео (клип/live/кавер), Джарвис покажет карточки с превью и предложит выбрать кликом или голосом («второе»).
- «Покажи картинку дня от наса» — астрономическое фото или видео дня NASA с описанием, прямо в окне ассистента, без браузера.

**🚚 Игры (Euro Truck Simulator 2 и другие)**
- «Статус грузовика», «круиз-контроль на 90», «прибавь ретардер».
- Джарвис сам предупредит о топливе, усталости водителя, штрафах, износе техники, сцепке/расцепке прицепа — без запроса, во время игры.
- ИИ озвучивает брифинг перед рейсом и итоги после сдачи груза (нужен ключ Groq/OpenAI/Gemini).

**📝 Помощник и заметки**
- «Напомни выключить духовку через 20 минут».
- «Режим диктовки» — печатает голосом в любое текстовое поле со знаками препинания.

**⚙️ Прочее**
- Голосовые макросы для приложений (Photoshop, Figma и другие через Менеджер расширений).
- Мониторинг ресурсов ПК, управление окнами, буфером обмена, почтой.

## ⚙️ Где искать настройки

Кнопка с шестерёнкой ⚙️ в интерфейсе, либо голосом: «открой настройки».

- **Вкладка «Голос»** — чувствительность микрофона, усиление, режим wake word и таймер «засыпания», калибровка одной кнопкой.
- **Вкладка «Интерфейс»** — темы, прозрачность, масштаб.
- **Менеджер расширений** — игровые профили и доп. навыки, устанавливаются по необходимости.

## 📦 Сборка в готовый `.exe`

Всё собирается через PyInstaller по спеке `jarvis.spec`, обёрнутой в `build.bat`.

```bash
pip install -r requirements-full.txt   # чтобы в сборку попали все опциональные фичи
pip install pyinstaller
build.bat
```

Скрипт сам:
1. Прогоняет PyInstaller по `jarvis.spec` (это может занять несколько минут — Silero TTS тянет PyTorch).
2. Копирует `assets/`, `audio/`, `models/`, `config_pack/` рядом с `Jarvis.exe`.
3. Копирует статичные данные (игровые профили, каталог расширений, ONNX-модель семантического NLU, кэш эмбеддингов) в `dist\Jarvis\data\` — но **не** ваши личные `jarvis_settings.json`, `.env`/`secrets.env` и логи, чтобы случайно не утекли API-ключи или история.

Результат — папка `dist\Jarvis\` с `Jarvis.exe` и всем необходимым рядом; переносится на другой ПК как есть (Windows 10/11 x64).

Если нужен инсталлятор (а не просто папка) — используйте `build_installer.bat` (собирает через `jarvis_installer.iss`, Inno Setup).

**Что НЕ копируется намеренно** (и это правильно): личные настройки, история команд, сохранённые API-ключи, отладочные логи — при первом запуске на новой машине они создадутся заново.

---

## 💡 Зачем это нужно

1. **Многозадачность** — не отвлекаясь на поиск нужной папки или настройки, особенно за рулём в игре.
2. **Скорость** — команды вроде очистки памяти или проверки погоды выполняются голосом за секунду.
3. **Приватность** — распознавание речи и логика команд работают локально; в интернет уходят только явно сетевые запросы (погода, YouTube, NASA, ИИ), и только если вы ими пользуетесь.

Если что-то работает не так — откройте Настройки → Голос → «ТЕСТ И КАЛИБРОВКА», это чинит 90% проблем с распознаванием.
