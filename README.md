# 🎙️ JARVIS: Next-Gen AI Voice Assistant

JARVIS — это мощный персональный ассистент с голосовым управлением, созданный для автоматизации повседневных задач, мониторинга состояния системы и интеграции с игровыми симуляторами (например, Euro Truck Simulator 2). Система обладает современным голографическим HUD-интерфейсом и продвинутыми алгоритмами обработки речи.

---

## ✨ Основные возможности

*   **🎙️ Голосовое управление**: Использование современных движков ASR (GigaAM, Vosk) и VAD (Silero) для точного распознавания команд.
*   **🗣️ Естественный синтез**: Озвучка ответов с помощью Silero TTS с высококачественными голосами.
*   **🖥️ Holographic HUD**: Футуристичный оверлей на рабочем столе для визуализации состояния ассистента.
*   **🚛 Интеграция с ETS2**: Полноценная поддержка телеметрии Euro Truck Simulator 2 (расход топлива, штрафы, навигация, круиз-контроль).
*   **📊 Системный мониторинг**: Отслеживание заряда батареи, задержек системы (Lag Hunter) и активных игровых процессов.
*   **📬 Уведомления**: Интеграция с Telegram для отправки уведомлений и логов.

## 🚀 Быстрый старт

### Требования
*   Python 3.10 или выше
*   Установленный PyAudio (может потребоваться компилятор C++ для сборки PortAudio)
*   Микрофон и колонки

### Установка

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/your-repo/jarvis.git
    cd jarvis
    ```

2.  Установите базовые зависимости:
    ```bash
    pip install -r requirements.txt
    ```

3.  Установите дополнительные компоненты (по необходимости):
    ```bash
    pip install -r requirements-full.txt
    ```

4.  Подготовьте модели:
    Загрузите модели ASR и VAD в папку `models/`.

### Запуск
```bash
python main.py
```

## ⚙️ Конфигурация

### .env файл
Создайте файл `.env` в корневом каталоге на основе `.env.example`:
```env
TELEGRAM_BOT_TOKEN=your_token_here
TELEGRAM_CHAT_ID=your_chat_id_here
JARVIS_VOICE_DEBUG=0
```

### Настройки (config_pack/config.py)
Основные параметры, такие как чувствительность микрофона (`MIC_GAIN`), пороги VAD и пути к моделям, настраиваются в файле `config_pack/config.py`.

---

## 🛠️ Сборка в EXE

Проект поддерживает автоматизированную сборку в один исполняемый файл с помощью PyInstaller.

1.  Запустите скрипт сборки:
    ```bash
    build.bat
    ```
2.  Результат будет находиться в директории `dist/Jarvis/`.

> [!IMPORTANT]
> При первой сборке процесс может занять несколько минут из-за анализа зависимостей PyTorch.

## 📁 Структура проекта

*   `main.py` — Точка входа в приложение.
*   `core/` — Ядро системы (обработка речи, диспетчер команд, логика двигателя).
*   `actions/` — Реализованные действия и команды.
*   `features/` — Дополнительные модули (ETS2 монитор, батарея и т.д.).
*   `ui/` — Графический интерфейс (HUD, диалоговые окна настроек).
*   `models/` — Директория для хранения моделей распознавания и синтеза.
*   `logs/` — Журналы работы (только критические ошибки).

---

## 🚑 Поддержка и Логи

Система настроена на минималистичное логирование. Все критические ошибки инициализации записываются в `logs/debug_init.log`. Если ассистент не реагирует на голос, проверьте `logs/voice_engine.log` (запись ведется только при наличии сбоев).
