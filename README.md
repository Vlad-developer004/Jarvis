# 🎙️ JARVIS: Экосистема Вашего Цифрового Пространства

[![Python Version](https://img.shields.io/badge/python-3.10%2B-blue.svg)](https://www.python.org/)
[![Status](https://img.shields.io/badge/Status-Fully_Functional-success.svg)](https://github.com/Vlad-developer004/Jarvis)

**JARVIS** — это не просто голосовой ассистент, а мощное решение для Windows, объединяющее искусственный интеллект, системную автоматизацию и глубокую интеграцию с игровыми симуляторами в единый футуристичный интерфейс. 

---

## 🌟 Зачем Вам JARVIS?

В отличие от стандартных решений, JARVIS ориентирован на **Power User**-ов и геймеров:
*   **Свобода рук**: Управляйте системой, медиа и рабочим окружением без касания клавиатуры.
*   **Игровое погружение**: Получайте данные телеметрии в реальном времени (например, из ETS2) прямо через голос и HUD.
*   **Приватность**: Обработка речи (ASR) и синтез (TTS) происходят **локально** на вашем компьютере.
*   **Эстетика**: Уникальный Holographic HUD делает работу с компьютером похожей на интерфейс из фантастических фильмов.

## 🛠️ Подробная Установка (Шаг за шагом)

Чтобы исключить любые ошибки при запуске, следуйте этой инструкции:

### 1. Подготовка Окружения
*   **Python 3.10+**: Скачайте и установите Python с [официального сайта](https://www.python.org/downloads/). **Важно**: При установке обязательно отметьте галочку **"Add Python to PATH"**.
*   **FFmpeg**: Необходим для обработки аудиопотоков.
    1.  Скачайте сборку с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/).
    2.  Распакуйте и добавьте путь к папке `bin` в системную переменную `PATH`.
*   **Visual C++ Redistributable**: Часто требуется для работы библиотек глубокого обучения (PyTorch).

### 2. Клонирование и Инициализация
Откройте терминал в нужной папке и выполните:
```bash
# Клонирование
git clone https://github.com/Vlad-developer004/Jarvis.git
cd Jarvis

# Создание виртуального окружения (рекомендуется)
python -m venv venv

# Активация окружения
# Для Windows:
venv\Scripts\activate
```

### 3. Установка Зависимостей
Выберите нужный уровень установки:
```bash
# Базовый уровень (Голос + Основы управления)
pip install -r requirements-base.txt

# Полный уровень (Все функции, включая HUD и сложные действия)
pip install -r requirements-full.txt

# Дополнительно (если будете использовать ИИ-зрение или веб-поиск)
pip install -r requirements-vision-game.txt
pip install -r requirements-web-qa.txt
```

## 🧠 Настройка Нейросетевых Моделей

JARVIS использует локальные модели для работы. Вам необходимо создать папку `models/` в корне проекта и разместить там:

1.  **Silero VAD**: Для обнаружения начала и конца речи.
2.  **ASR Модель**: 
    *   **GigaAM** (высокая точность) или **Vosk** (быстрая работа на слабых ПК).
3.  **Silero TTS**: Для озвучки ответов.

**Структура папки моделей должна выглядеть так:**
```text
models/
├── silero_vad.jit
├── vosk-model-small-ru/
└── tts_models/
```

## 🗣️ Каталог Голосовых Команд

JARVIS понимает сотни команд. Вот основные категории:

### 🎵 Медиа и Ютуб
*   *"Открой ютуб"* — Запуск приложения YouTube.
*   *"Пауза / Играй"* — Управление воспроизведением.
*   *"Следующий трек / Громче"* — Управление звуком и очередью.

### 🖥️ Управление Системой
*   *"Сколько сейчас времени?"* — Голосовое оповещение о времени.
*   *"Какой заряд батареи?"* — Проверка состояния аккумулятора.
*   *"Сверни все окна"* — Очистка рабочего стола.
*   *"Сделай скриншот"* — Сохранение экрана в папку `data/screenshots`.

### 🚛 Euro Truck Simulator 2 (ETS2)
*   *"Статус грузовика"* — Отчет о топливе, повреждениях и дистанции.
*   *"Заглуши двигатель"* — Выполнение последовательности действий в игре.
*   *"Сколько до конца рейса?"* — Данные из навигатора игры.

### 📬 Продуктивность
*   *"Проверь мою почту"* — Чтение последних заголовков писем.
*   *"Новая заметка: [текст]"* — Быстрая запись идеи.

## 🚛 Интеграция с ETS2 (Специальный шаг)

Для работы игровых функций необходимо установить плагин телеметрии:
1.  Убедитесь, что игра закрыта.
2.  Запустите встроенный инсталлятор:
    ```bash
    python actions/ets2_telemetry_installer.py
    ```
3.  Скрипт автоматически найдет папку с игрой и установит необходимую DLL.

## ⚙️ Конфигурация (.env)

Скопируйте `.env.example` в `.env` и заполните:
*   `TELEGRAM_BOT_TOKEN`: Для получения отчетов в Telegram.
*   `TELEGRAM_CHAT_ID`: Ваш ID в Telegram.
*   `MIC_GAIN`: (Опционально) Усиление микрофона, если вас плохо слышно (настраивается в `config_pack/config.py`).

---

## 📁 Структура Проекта (Где что лежит?)

*   `main.py`: Сердце системы. Запускает потоки прослушивания и HUD.
*   `core/`: Логика обработки звука (VAD, ASR, TTS) и диспетчер команд.
*   `actions/`: Каждый файл здесь — это новая суперспособность JARVIS (от YouTube до управления Bluetooth).
*   `features/`: Фоновые задачи — мониторинг батареи, лагов и игровых состояний.
*   `ui/`: Все, что касается визуальной части (Hologram HUD на PySide6).
*   `logs/`: Если что-то пошло не так, загляните сюда.

## ❓ Часто задаваемые вопросы (Troubleshooting)

**В: JARVIS меня не слышит, что делать?**
О: Проверьте уровень `MIC_GAIN` в `config_pack/config.py` или убедитесь, что в системе выбран правильный микрофон по умолчанию.

**В: Ошибка "FFMPEG not found".**
О: Убедитесь, что путь к папке ffmpeg/bin добавлен в системную переменную PATH и вы перезагрузили терминал.

**В: Программа закрывается сразу после запуска.**
О: Проверьте файл `logs/debug_init.log`. Чаще всего проблема в отсутствии моделей в папке `models/`.
