### 1. ❌ Критическая ошибка в `actions/filesystem.py`

**Файл:** `actions/filesystem.py` (строка 306)  
**Функция:** `_find_subdir_ci_or_fuzzy()`  
**Проблема:** Переменная `best` инициализируется, но НИКОГДА не обновляется в цикле. Это приводит к тому, что fuzzy matching не работает правильно.

**Код ДО:**
```python
for entry in _list_subdirs(base):
    # ... код ...
    score = 0
    for q in query_vars:
        for e in ev:
            s = calculate_match_score(q, e)
            if s > score:
                score = s
    # ОШИБКА: best никогда не обновляется!
if best is not None and best[0] >= 82:
    return best[1]
```

**Код ПОСЛЕ:**
```python
for entry in _list_subdirs(base):
    # ... код ...
    score = 0
    for q in query_vars:
        for e in ev:
            s = calculate_match_score(q, e)
            if s > score:
                score = s
    # ИСПРАВЛЕНИЕ: теперь обновляем best
    if best is None or score > best[0]:
        best = (score, entry)
if best is not None and best[0] >= 82:
    return best[1]
```

**Влияние:** Команда "зайди в..." не могла найти папку при нечётком совпадении имени.  
**Статус:** ✅ Исправлено

### 2. ❌ Опечатки в `core/handler/commands/utils.py`

**Файл:** `core/handler/commands/utils.py` (строки 76, 84, 88)  
**Проблема:** В сообщениях об ошибках есть случайные символы `+` в середине слов (очевидно, ошибка при копировании).

**Найдено:**
- Строка 76: `'Нет изменений для комм+ита.'` → ❌ неправильно
- Строка 84: `'Комм+ит отменён.'` → ❌ неправильно
- Строка 88: `'Вы не выбр+али ни одного файла.'` → ❌ неправильно

**Исправлено на:**
- ✅ `'Нет изменений для коммита.'`
- ✅ `'Коммит отменён.'`
- ✅ `'Вы не выбрали ни одного файла.'`

**Влияние:** Команда `git_commit` выдавала странные сообщения об ошибках.  
**Статус:** ✅ Исправлено
