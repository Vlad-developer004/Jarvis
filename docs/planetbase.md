# Planetbase: мод и голосовое управление

Схема: C#-мод `PlanetbaseTelemetry` (в игре) <-> файлы в `Documents\Planetbase` <-> `features/planetbase/` (Jarvis).

## Файлы обмена
- `jarvis_telemetry.json` — мод пишет раз в 2 с (сбор в главном потоке Unity).
- `jarvis_command.txt` — Jarvis пишет команду (3 строки: id, команда, аргумент); мод исполняет и отвечает в `jarvis_command_result.json`.
- `jarvis_modules.json` — данные о постройках (команда `dump_modules`), используются как знания для LLM.

## Команды мода (`mods/PlanetbaseTelemetry/`)
`build:<Key>` (призрак постройки; размер и место выбирает игрок), `show:<kind>` (выбор + камера), `speed`, `pause`, `unpause`, `alert`, `landing`, `priority`, `save`, `dump_modules`, `list_modules`.

Сборка без .NET SDK: `csc.exe` из `C:\Windows\Microsoft.NET\Framework64\v4.0.30319` с `-noconfig -nostdlib` и ссылками на `mscorlib.dll`, `netstandard.dll`, `System*.dll`, `Assembly-CSharp.bak`, `UnityEngine*.dll` из `Planetbase_Data\Managed`; исходники `PlanetbaseTelemetry.cs` и `GameCommands.cs`. Готовая DLL — `data/integrations/planetbase/PlanetbaseTelemetry.dll`, копируется в игру установщиком при разном хеше (игра должна быть закрыта).

## Голос
- Строительство: «построй солнечную панель» и т.п. (28 построек).
- Выбор/камера: «покажи больных», «где сломано», «где нарушители», «покажи склад», «следующий».
- Управление: «скорость три», «нормальная скорость», «продолжай», «запрети/разреши посадку колонистов/гостей/торговцев», «приоритет на кислород».
- Советник: «что делать» (топ-3 по правилам из телеметрии), «построй рекомендованное».
- Прогноз: «на сколько хватит» (ETA по тренду для энергии, воды, еды, медикаментов).
- Риски планеты: «какие риски» (песчаные бури, вспышки, метели, метеориты, грозы). Уровни из игры: нет / низкий / переменный / высокий. На планетах с высоким риском бурь порог «мало энергии/воды» растёт (до +20 п.п.); советник предлагает накопитель энергии заранее, противометеоритный лазер и громоотвод при риске метеоритов и гроз (когда их ещё нет и построено 10+ модулей).
- Журнал: «что случилось».
- Автопилот (выкл. по умолчанию): «включи/выключи автопилот». При вторжении — красный код и закрытая посадка колонистов; при катастрофе — сброс скорости. Возвращает только то, что изменил сам.
- Автосохранение (вкл. по умолчанию): каждые 10 минут и перед опасностью, в слоты `jarvis_auto_1..3` (свои слоты игрока не трогает). Откат — загрузкой этих слотов из меню игры.
- Вопросы по игре («объясни…», «скажи…»): к системному промпту LLM добавляются состояние колонии, текущие проблемы и таблица построек из игры.

## Озвучка
Объявления и ответы Planetbase и ETS2 проходят через `core/speech/pacing.py::add_pauses`: паузы `<break/>` между предложениями (620 мс, длиннее естественной паузы Silero ~500 мс), после тире (320 мс) и запятых в длинных фразах (180 мс), плюс одно выделение `*слово*` на срочное слово («внимание», «критическая»…). Уже размеченный текст (LLM-озвучка) не меняется. Значения подобраны замером реального синтеза: явная пауза заменяет естественную, а не добавляется к ней.

## Ограничения
- Мод читает состояние игры и выполняет команды в главном потоке, поэтому команды (постройка, скорость, показ) работают, только пока окно игры отрисовывается (в фокусе). Телеметрия при этом остаётся доступной: отдельный поток обновляет «пульс» `ts`, а данные берутся из последнего кадра (`collected_ts`; в фоне игра стоит, так что данные верны). Команда, не выполненная за 3 секунды, отбрасывается.
- Обновить DLL мода можно только при закрытой игре; при запущенной Jarvis оставляет установленную версию.
- Замок на шлюзах в игре снимается сам; «заблокируй шлюзы» включает жёлтый код.
- Автоматического подбора места для построек нет.
- Смысл части полей телеметрии (`n_sick`, `mod_unpowered`, `storage_space_avg`) выведен из названий методов игры и требует проверки в игре.
